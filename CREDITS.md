# Credits

Everything in this repository is original work made for this project; no third-party
assets are included.

| Asset | Where | How it was made |
|---|---|---|
| Knight, corridor, barricades, beams, crates, axes, coins, gems, power-ups | `Assets/Scripts/Game` | Built at run time from Unity's primitive meshes and a few flat-shaded meshes made in code (`Models.cs`, `Shapes.cs`) |
| Materials, particle texture, scene, app icon, UI panel settings | `Assets/Art`, `Assets/Scenes`, `Assets/UI` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| Music (run theme, title theme) and sound effects | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded with ffmpeg) |
| HUD layout and style | `Assets/Scripts/Game/Hud.cs`, `Assets/UI/Hud.uss` | Written for this project (UI Toolkit in code and USS) |
| Font | — | Unity's default runtime font |

## Removed third-party content

Earlier versions of this repository (before the `fix/asset-licensing` changes) contained
Unity Asset Store packages under `Assets/Externa lAssets` and `Assets/Animations`: Synty
POLYGON Knights and POLYGON Starter, Dungeon Traps, Gems Ultimate Pack, Responsive Energy
Shield (ForceShield), BOXOPHOBIC Skybox Cubemap Extended, Simple Sky and the Basic Motions
animation pack, plus a music track (`Endless Runner.ogg`) and a coin sound (`Pickup_Coin.wav`)
of unrecorded origin. The Asset Store licence does not allow redistributing those files in a
public repository, so they, and the scenes and prefabs built on them, were removed and the
game was rebuilt on original, generated art and audio. They remain in the git history, which
was not rewritten.
